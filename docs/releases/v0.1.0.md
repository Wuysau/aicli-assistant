# AI CLI Assistant v0.1.0

首个可试用的 Windows 桌面版本。

## 当前包含

- 首批 10 个内置终端工作流模板
- 本地关键词/意图匹配
- 推荐环境、推荐 Shell、推荐命令和下一步建议
- 规则驱动的风险提示
- 最近记录、模板活跃度、偏好项和最近搜索的本地持久化
- Windows 桌面端“发送到终端输入框但不自动执行”
- 可选的受约束 AI 补充说明

## 本次发布资产

- `AI CLI Assistant_0.1.0_x64-setup.exe`
- `AI CLI Assistant_0.1.0_x64_en-US.msi`

## 适用范围

- Windows x64
- 适合展示、试用和本地验证

## 当前限制

- 当前未做代码签名，首次下载运行时可能看到 Windows SmartScreen 提示
- 终端插入能力优先支持 Windows Terminal 和经典控制台窗口
- 当前版本仍以本地模板和规则为主，不是通用聊天助手
