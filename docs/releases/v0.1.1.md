# v0.1.1

This release tightens the app around a faster command-panel workflow and makes the AI provider flow more usable.

## Highlights

- Reworked the workbench into a shorter command-panel flow with lighter result presentation.
- Moved templates, recent records, settings, validation tools, and explanatory content into secondary areas.
- Rebuilt the result area to focus on recommended environment, shell, command, and primary actions first.
- Fixed template quick-apply so it no longer locks later requests into template mode.
- Improved provider handling by falling back to another usable default provider when the configured default is unavailable.
- Reset provider-specific fields when changing provider type in settings.
- Added clearer off-topic handling for non-terminal questions instead of making the result panel look broken.

## Notes

- Core workflow still stays template/rule first.
- AI remains a constrained supplement rather than a free-chat primary flow.
- Windows desktop bundles are still the main supported release target.
